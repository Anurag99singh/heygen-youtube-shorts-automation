# Distribution copy
Read the actual approved narration/video transcript, source C and topic B. Verify all claims against the original source; distinguish announced, available and planned. Do not invent benefits, prices, benchmarks, endorsements or personal experience. Preserve limitations and dates. If source is unavailable, block unsupported drafting rather than speculate.

Write U: a clear YouTube title, normally 40–65 characters, max100; topic/product plus concrete useful angle, no clickbait.
Write V: 45–80-word YouTube description. First sentence explains the useful takeaway. Add 1–2 specific details and an honest limitation when material. Finish with Source: original URL and 2–3 relevant hashtags including #Shorts. No generic hype or fabricated CTA.
Write AA: distinct Instagram-native caption, normally 40–90 words. Strong factual first line, short readable paragraphs, practical implication, optional genuine specific question. No fake urgency or engagement bait. Include source attribution/link where useful without promising clickable caption links. Do not include hashtags in AA.
Write AB: 3–5 relevant specific hashtags, space-separated, no irrelevant trending tags, duplicate tags, guaranteed reach claims or platform boilerplate.

Return exact fields U/V/AA/AB plus source verification and any uncertainty. Count lengths/words and hashtag number; verify copy describes the actual approved video, not unshown capabilities. Never put this copy in spoken production Doc or confuse it with burned-in subtitles. Save proposed copy before human distribution review. Any change after approval invalidates AD and requires fresh approval; preserve already-sent history. Never send email or publish from this skill.
